A make.fun entry: one line, in the GPS's own voice, excusing itself for
sending the driver down the wrong road.

> I said "recalculating" to sound confident, but I've actually been guessing since the roundabout.

`main.ts` writes exactly that line (96 characters) to `/output/entry.txt`,
checks it against the 1–200 character gate, and re-reads the file to
confirm the content matches byte-for-byte.

- Competition: [The GPS Swears It Was a Shortcut](https://make.fun/bounty/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9)
- Entry: one line of plain text, no setup, no dialogue tags — just the excuse itself.
